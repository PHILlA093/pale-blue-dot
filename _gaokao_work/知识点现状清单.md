# 穷观 · 知识点现状清单

> **本文件为新增文件**,生成过程只读取了 4 个数据文件,未修改项目内任何已有文件。

> **解析方法(实际所用)**:用 node 以 UTF-8 读入源文件 → `indexOf("window.<变量名>")` 定位赋值语句 → 取 `=` 之后的全部文本 → 去掉结尾分号 → 直接 `JSON.parse`。
> 4 个文件的赋值体**都是合法 JSON 字面量**,`JSON.parse` 全部一次成功,因此没有采用 `new Function` 求值这条路。
> 之所以不用 PowerShell 的 `Get-Content`/`ConvertFrom-Json`:数据文件是 UTF-8,而本机 Windows PowerShell 5.1 默认按 ANSI 代码页读取,会直接把中文读成乱码。

### 4.3 命名规律

**一句话概括**:5 个板块用「中文类别词 + 分隔符 + 内容」命名,只有 `words`(词汇总览)用**裸英文词条**;每个板块有独立的 id 前缀与编号格式。

| 板块 id | 名称前缀样式 | 例 | id 前缀 | id 编号格式 | id 实测区间 |
|---|---|---|---|---|---|
| `roots` | `词根 <拉丁词根>`(**无** `·` 分隔符,用半角空格) | `词根 aer/aero` | `root-` | 连字符 + 3 位序号 | `root-001` → `root-203` |
| `topics` | `主题·<中文场景>` | `主题·校园学习` | `tpc-` | `t` + 2 位(个位补零) | `tpc-t01` → `tpc-t99` |
| `sentence` | `句型·<结构或时态>` | `句型·主系表` | `S` | `S` + 3 位 | `S001` → `S100` |
| `grammar` | `语法·<主题>`,可用 `:` 或 ` vs ` 再分 | `语法·名词:数与格`;`语法·完成时:现在完成 vs 过去完成` | `G` | `G` + 3 位 | `G001` → `G040` |
| `phrase` | `词组·<英文短语>` | `词组·in the end` | `P` | `P` + 3 位 | `P001` → `P500` |
| `words` | **裸词条,无中文前缀、无分隔符** | `abandon` / `abnormal` | `w-`(+1 个 `words-`) | `w-` + 4 位,**跳号** | `w-0001` → `w-3509` |

补充说明(均可核对):

1. **词根板块没有中文释义**,名称就是「词根 + 拉丁词根拼写」,如 `词根 aer/aero`、`词根 ag/act`、`词根 aster/astr/astro`,同一词根的变体用 `/` 连接。
2. **句型板块是两种维度混装**:既有句法结构类(`句型·主系表`、`句型·主谓双宾`、`句型·There be 存在句`),又有时态类(`句型·一般现在时`、`句型·现在完成时`)。
3. **句型与语法两个板块内容重叠**:时态既出现在 `sentence`(`句型·一般现在时` 等),也出现在 `grammar`(`语法·八大时态总览`、`语法·一般现在与进行对比`),说明板块不是互斥切分。
4. **词组板块按「核心词的字母序」而非字面字符串序**排列:第 2–5 条依次是 `词组·be about to do`、`词组·above all`、`词组·by accident`、`词组·be accustomed to doing`,即 `by accident` 归入 accident 的 a 段,而 `be about to` 归入 about 的 a 段。
5. **词汇总览的 id 是稀疏编号**:1114 条只占用 `w-0001`–`w-3509` 中的一部分,对应入口节点自述的「主表 3555 条 + 补遗 85 条,编号 1-3640」,即按**考纲词表序号**编号,不是连续序号。
6. **英语存在两套 id 体系**:语义前缀式(`root-`/`tpc-`/`S`/`G`/`P`/`w-`)与标题式入口节点(`words-index`)。

**命名规律总结**:英语知识点名 = 板块类别标签 + 内容本体。类别标签共 5 种(`词根 `/`主题·`/`句型·`/`语法·`/`词组·`),唯一例外是 `words` 板块的裸英文词条。**这是按「语言知识类型」分类,不是按教材单元分类**(详见第六节)。

### 6.3 逐科判断

#### 数学 —— 不是章节体系,是「考点专题」体系

10 个板块 = 5 个大板块 + 5 个小板块,但两组的划分逻辑并不相同:

- **5 个大板块是跨册主题聚合**,每个都横跨至少两册人教A版(2019):
  - `calculus` 函数与导数:把必修一第 3 章(函数的概念与性质)、第 4 章(指数函数与对数函数)与选择性必修二第 5 章(一元函数的导数及其应用)并成一个板块;
  - `trig_seq` 三角函数与数列:把必修一第 5 章(三角函数)与选择性必修二第 4 章(数列)并成一个板块;
  - `analytic` 解析几何:把选择性必修一第 2 章(直线和圆的方程)与第 3 章(圆锥曲线的方程)并成一个板块;
  - `stats` 统计与概率:横跨必修二第 9、10 章与选择性必修三;
  - `solid` 立体几何:横跨必修二第 8 章与选择性必修一第 1 章(空间向量与立体几何)。
- **5 个小板块恰恰是教材里独立的章**,反而比大板块更接近教材粒度:`sets` 集合与逻辑(6 条)、`inequality` 不等式(8 条)、`vector` 向量(9 条)、`complex` 复数(5 条)、`counting` 排列组合与二项式定理(7 条),分别对应必修一第 1、2 章,必修二第 6、7 章,选择性必修三第 6 章。

**判断**:数学板块体系**不是**按教材章节组织的。它是「大专题(跨册合并)+ 章节碎片(单独成小板块)」的混合,同一层级里两种粒度并存 —— 这是与教材对齐时最主要的障碍。

#### 物理 —— 最接近教材章节,但不是纯章节

10 个板块的名称几乎就是教材章标题的直译(牛顿运动定律、机械振动与机械波、热学……),6 个大板块 + 4 个小板块,且 **10 个板块的 id 前缀全部单一来源**,说明它是从章节单元直接长出来的。但有三处明确偏离:

1. **4 处跨册合并**:
   - `motion` 直线运动与相互作用 = 必修一第 1 章(运动的描述)+ 第 3 章(相互作用——力),跳过了第 2 章;
   - `energy` 机械能与动量 = 必修二第 8 章(机械能守恒定律)+ 选择性必修一第 1 章(动量守恒定律),把力学两大守恒定律并成一块;
   - `magnet` 磁场与电磁感应 = 必修三第 13 章 + 选择性必修二第 1、2、3 章(安培力与洛伦兹力 / 电磁感应 / 交变电流);
   - `light` 光学与电磁波 = 选择性必修一第 4 章(光)+ 选择性必修二第 4 章(电磁振荡与电磁波)+ 选择性必修三的「波粒二象性」部分。
2. **一个教材章被劈成两个板块**:人教版选择性必修三第 4 章「原子结构和波粒二象性」在本库里被拆开 ——「光电效应」「光的波粒二象性与物质波」落在 `light`(光学与电磁波),而「原子结构(α粒子散射)」「氢原子光谱与玻尔模型」落在 `atom`(原子结构与近代物理)。**这是物理板块不纯按章节走的直接证据。**
3. **板块内混入了模型/题型条目**,例如 `newton` 里的「传送带问题」「板块(滑块)模型」「瞬时性与临界问题」,`curve` 里的「双星与多星系统」,`elect` 里的「质谱仪与回旋加速器」。不过它们都寄生在对应章节板块内部,没有单独成立「题型板块」。

**判断**:物理是四科中**最接近教材章节**的一科,板块基本可按「章标题关键词」映射到人教版的章,只需处理上述 4 处跨册合并和 1 处同章拆分。物理**没有**任何「功能/题型」性质的独立板块。

#### 化学 —— 大板块是教材模块,小板块是功能/题型

8 个板块 = 4 个大板块 + 4 个小板块,两组的性质截然不同:

- **4 个大板块基本等于教材的「模块/册」**,而不是章:
  - `foundation` 基础化学(24 条)= 必修第一册 + 必修第二册合并,内部同时装着「物质的分类」「离子反应」「氧化还原」「物质的量」「元素周期律」(必修一)和「硫及其化合物」「氮及其化合物」「硅及其化合物」「化学工艺流程」(必修二);
  - `structure` 结构化学(15 条)= 选择性必修二《物质结构与性质》全册,内部正好是「原子结构 / 分子结构 / 晶体结构」三章;
  - `principle` 化学反应原理(15 条)= 选择性必修一《化学反应原理》全册(热效应 / 速率与平衡 / 水溶液离子平衡 / 电化学);
  - `organic` 有机化学(19 条)= 选择性必修三《有机化学基础》。
  注意:`structure`、`principle`、`organic` 的板块名**直接就是教材书名**(物质结构与性质、化学反应原理、有机化学基础),这恰好证明它们的划分依据是「册」而非「章」。
- **4 个小板块是彻头彻尾的功能/题型分类**,任何一个都不能对应某一章:
  - `avogadro` 阿伏伽德罗常数(3 条)—— 这是**典型高考题型**,板块内条目直接叫「阿伏伽德罗常数与陷阱模型」「**NA 题判断方法**」,教材里从来没有「阿伏伽德罗常数」这一章;
  - `notation` 化学用语(3 条)—— 跨章技能维度(化学式 / 电子式 / 方程式书写),分散在必修一各章;
  - `lab` 化学实验(4 条)—— 把分散在各册的实验内容抽出来做功能归类;
  - `life` 化学与生活(3 条)—— STSE 主题聚合,横跨必修二与选修。

**判断**:化学是「模块 + 功能」的混合体系。4 个大板块可以 1:1 落到教材的「册」,但对齐到「章」还需要再拆一层(尤其 `foundation` 要拆回必修一/必修二各章);4 个小板块属于跨章的功能分类,**不应该硬塞进某一章**,建议保留为独立的标签层(题型标签 / 技能标签),与章节维度正交使用。

#### 英语 —— 完全不是章节体系,而是「语言知识维度」

6 个板块:词根词缀(203)、主题场景(21)、核心句型(100)、语法知识(40)、高频词组(500)、词汇总览·词点层(1114)。判断依据:

1. **没有任何一个板块名能对应人教版(2019)的教材单元。** 英语教材是按主题单元组织的(必修 1–3 + 选择性必修 1–4,共 30 多个 Unit,如 Teenage Life、Travelling Around),而本库的板块名全是「词根 / 主题 / 句型 / 语法 / 词组 / 词汇」——**语言知识类型**,不是教学单元。
2. **`words` 板块的编号方式是「考纲词表序号」而非「教材出现顺序」。** 入口节点 `words-index`(名称「英语词库总览(1-3640)」)的 content 自述「主表 3555 条 + 补遗 85 条,编号 1-3640」,且 id 是稀疏的 `w-0001`–`w-3509`。它对齐的是**考纲/词表**,不是教材单元。
3. **板块之间不互斥,存在重叠**,说明它们被设计成「查询入口」而不是「章节切分」:同一个时态知识既在 `sentence`(`句型·一般现在时`)又在 `grammar`(`语法·八大时态总览`);`words` 里的单词与 `roots` 里的词根族、`phrase` 里的短语也存在天然交叉。
4. **`topics`(主题场景)最接近教材的主题式组织,但粒度对不上**:只有 21 条(`主题·校园学习`、`主题·饮食餐饮`……),而人教版一个单元一个主题,30 多个单元无法用 21 个粗类覆盖;而且它的 t99 编号(`tpc-t99`)暗示这原本是个 99 项的清单。

**判断**:英语板块体系与教材章节是**零对齐**的 —— 它不是「章节划分得不好」,而是**压根没有章节这一维**。要对齐人教版,必须新建一层「教材单元(必修1–3 / 选必1–4 的 Unit)→ 词 / 短语 / 句型 / 语法点」的映射表,现有 6 个板块只能作为知识点自身的属性标签。

### 6.4 对后续「按人教版教材对齐」的直接影响

| 科目 | 需要做的动作 | 预估工作量 |
|---|---|---|
| 物理 | 最省事。按「章标题关键词」把 10 个板块映射到人教版章;处理 4 处跨册合并(拆分 `energy`/`magnet`/`light`/`motion`)与 1 处同章拆分(把「光电效应/波粒二象性」从 `light` 归回 `atom` 所属的选必三第 4 章) | 小 |

### 6.5 补充发现:数学库里有 6 条内容属于人教A版(2019)已删除的考点

这一条是核对教材章节时顺带发现的,但它会**直接导致对齐失败**,所以单列出来。

人教A版(2019)相比 2004 课标版做了较大删减,官方口径是「删除了**极坐标与参数方程、程序框图、算法初步、三视图、线性规划、命题之间关系、逻辑连接词、定积分**等内容」(来源:[2019年高中数学新教材正式发布](https://m.163.com/dy/article/EER7SG6R0518VCG2.html))。把这 8 项拿去和 `data.js` 逐条比对:

| 已删除的考点 | 本库是否有 | 命中的知识点(名称[id],板块,importance/core) |
|---|---|---|
| 定积分 | **有,3 条** | 定积分的概念与微积分基本定理[`calc-integral`] / 定积分的简单应用(面积)[`calc-integral-app`] / 曲边梯形与面积思想[`calc-curve-trap`](均在 `calculus`,importance 2/2/1,core 2/2/1) |
| 线性规划 | **有,1 条** | 简单线性规划[`ineq-lp`](`inequality`) |
| 极坐标与参数方程 | **有,1 条** | 参数方程与极坐标[`ana-param`](`analytic`) |
| 三视图 | **部分有,1 条** | 三视图与直观图[`solid-views`](`solid`)—— 该条把已删的「三视图」与仍保留的「直观图」(必修二 8.2)合并在同一个知识点里,需要拆开 |
| 程序框图 / 算法初步 | 无(名称层 0 命中) | — |
| 逻辑连接词 / 命题之间关系 | 无(名称层 0 命中) | 注:`sets` 板块有「常用逻辑用语[`set-logic`]」,但该章本身在 2019 版仍是必修一第一章,属有效内容,只是内部细分可能过时 |

**结论:需要人工复核的有 6 条**——5 条明确对应已删除考点(`calc-integral`、`calc-integral-app`、`calc-curve-trap`、`ineq-lp`、`ana-param`),加 1 条部分涉及(`solid-views`)。

**为什么这件事重要**:这 6 条全部落在数学板块里,而且分布很有规律 —— 3 条集中在 `calculus`(该板块共 19 条,占 15.8%),另外 2 条分别落在 `inequality` 和 `analytic`。也就是说,**数学库是「新课标主体 + 旧课标残留」的混合体**;这同时反过来说明:数学板块的划分依据更可能是「历年高考考点汇编」而不是现行教材目录 —— 旧考点被保留了下来。

反过来,物理 / 化学 / 英语三科没有做同口径核对,但英语的入口节点自称对齐「3500 / 3640 词表」,化学的板块名直接沿用现行教材书名,这三科从命名上更像是对着现行教材做的,风险低于数学。

### 6.6 一句话总结

**物理是按章组织的(最接近教材),化学是按「册 + 功能标签」组织的,数学是按「跨册考点专题」组织的,英语则完全没有教材维度、是按语言知识类型组织的。** 四科里只有物理能近乎直接地映射到人教版章节;数学和英语需要先做结构改造,化学需要把功能型小板块从章节体系里摘出去。
