穷观学习 · 桌面版 v2.4.2 —— 怎么装、怎么开
==================================================

一、安装(推荐,三步)
  1. 解压「穷观学习_桌面版_v2.4.2_安装包.zip」(用 Windows 自带的解压就行)
  2. 双击里面的「穷观学习_安装程序.exe」
  3. 点「开始安装」—— 装完桌面会出现「穷观学习」快捷方式,双击它就能用

  默认装到:C:\Users\<你的用户名>\AppData\Local\Programs\穷观学习
  · 不需要管理员权限,不弹 UAC
  · 想换地方就在安装界面点「浏览…」
  · 卸载:设置 → 应用 → 已安装的应用 → 穷观学习 → 卸载
    (开始菜单里也有「卸载 穷观学习」)

二、如果 Windows 弹出「Windows 已保护你的电脑」
  本程序没有购买代码签名证书,SmartScreen 会拦一下。
  点「更多信息」→「仍要运行」即可。这是未签名程序的常规提示,不是病毒。

三、运行环境
  · Windows 10 / 11(64 位)
  · .NET Framework 4.8 —— Win11 自带,Win10 一般也有
  · Microsoft Edge WebView2 运行时 —— Win11 自带;
    若提示缺失,把 Microsoft Edge 更新到最新版即可(Edge 会自带它)
  安装程序在装完时会自动检查这两项,缺哪个会告诉你上哪下。

四、不想安装?(免安装用法)
  仓库里的「桌面版\」文件夹就是免安装版:整个文件夹拷到 U 盘或任意位置,
  双击里面的「穷观学习.exe」即可。

  ⚠ exe 不能单独拷走 —— 它不是真正的单文件程序,必须和这 3 个 dll 放在一起,
    少一个都打不开:
       Microsoft.Web.WebView2.Core.dll
       Microsoft.Web.WebView2.WinForms.dll
       WebView2Loader.dll

  数据库\qg_corpus.txt 是高考真题语料(约 47 MB):删掉不影响启动,
  但「破卷」会少掉本机真题档案这一路素材。

五、手机版
  见仓库 mobile-apk 分支的「手机版\穷观学习.apk」(安卓 5.0 以上,免安装)。
