# 穷观 · 手机版

> 高考知识网络(3D 知识云 + 破卷 AI 出题 + 观澜 AI 演示问答)的**手机版本**。
> 同一份代码也支持桌面宽屏(≥769px 时布局与桌面版一致),但本目录是**为手机做的**。

---

## 1. 快速开始(Windows)

### 方式一:双击启动(推荐)

双击 **`启动手机版.bat`**。它会:

1. 检查 Node.js;
2. 用 `ipconfig` 找出本机局域网 IPv4,在窗口里打印手机该访问的网址;
3. 启动 `node server.js 8080`;
4. 自动打开电脑浏览器 `http://127.0.0.1:8080/` 方便自测。

> `启动手机版.bat` 的内容是**纯 ASCII**(不含任何中文)—— cmd 用 OEM 代码页解析 .bat,
> 混入中文字节会破坏脚本。所以窗口里的提示都是英文,这是刻意的。

### 方式二:命令行

```bat
cd /d E:\workspace\穷观手机版
node server.js            :: 默认 8080
node server.js 8081       :: 换端口
node server.js 8080 127.0.0.1   :: 只监听本机(手机就连不上了,仅自测用)
```

浏览器打开 <http://127.0.0.1:8080/>。

## 2. 手机怎么访问

1. **手机和电脑连同一个 Wi-Fi**(同一个路由器、同一个网段)。
2. 看 `启动手机版.bat` 窗口里打印的那一行:

   ```
   http://192.168.x.x:8080/
   ```

   端口若被占用换了号,记得跟着改。
3. 手机浏览器地址栏输入这个地址即可。
4. **第一次运行 Windows 会弹防火墙提示 → 必须勾选「专用网络」并允许**,
   否则手机连不上电脑(这是最常见的原因)。
5. 连不上时自查:
   - 电脑上 `ipconfig` 看无线网卡的 IPv4 是不是窗口里打印的那个;
   - 电脑浏览器先访问 `http://127.0.0.1:8080/` 确认服务本身是好的;
   - 有些路由器开了「AP 隔离 / 客户端隔离」,会禁止同网段设备互访,需要在路由器里关掉。

> 局域网地址是 `http://`(非安全上下文),所以**手机上浏览器不会注册 Service Worker**,
> 也就是没有 PWA 离线缓存。这是浏览器规则,不是 bug;APK 与 `localhost` 下正常。

## 3. AI Key 怎么填

- 破卷页(`train.html`)顶部的 **DeepSeek API Key** 输入框,或
- 观澜页(`guanlan.html` / 主页侧栏「🌊 观澜」面板)弹出的 Key 行。

粘贴 `sk-…` → 点「保存」。两处**共用同一个 Key**(存在浏览器 `localStorage` 的 `qg_ds_key`)。

- Key **只保存在这台手机的浏览器里**,不会上传到任何地方(除了请求头里的 `Authorization` 发给 DeepSeek)。
- 手机版自带的本地服务器 `server.js` **不读取、不落盘、不打印** Key 与请求体。
- 破卷页的「🗑 清除」会删掉 Key 与运行记录。
- 获取 Key:<https://platform.deepseek.com/api_keys>(DeepSeek 官方,按量计费)。

### AI 请求走哪条路(三种环境自动选择)

代码在 `js/ainet.js`,唯一入口 `window.QGAi.request(...)`,调用方(破卷 / 观澜)不需要关心环境:

| 模式 | 触发条件 | 请求路径 |
|---|---|---|
| **A · 桌面宿主** | `window.chrome && window.chrome.webview` | 交给 WebView2 桌面宿主代发(桌面版行为不变) |
| **B · Capacitor 原生壳(APK)** | `window.Capacitor.isNativePlatform() === true` | **直连** `https://api.deepseek.com/chat/completions`(CapacitorHttp 走原生层,无 CORS 问题,**不绕 `/api/ds`**) |
| **C · 普通浏览器(局域网访问)** | 以上都不是 | `POST /api/ds` → 由本地 `server.js` 反向代理转发到 DeepSeek |

浏览器控制台里执行 `QGAi.describe()` 可看到当前走的是哪条。

## 4. 手机上能做什么 / 不能做什么

### ✅ 可用

| 功能 | 说明 |
|---|---|
| 3D 知识云 | 单指拖动旋转、双指捏合缩放、轻触光点选中、双击聚焦、⌖ 重置视角 |
| 五科切换 | 数学 132 点 / 化学 86 点 / 物理 92 点 / 英语 3053 点 / 生物 137 点 |
| 关键词搜索 | 顶栏第二行,点结果直接跳转并弹出详情 |
| 知识点详情 | 底部抽屉(可上下拖拽、内部滚动、MatJax 公式排版) |
| 板块筛选 / 坐标解读 / 定义新知识点 | 左侧全屏抽屉里(点顶部遮罩、向右滑动、或再点 ☰ 关闭) |
| 破卷 AI 出题 | 见下面「打折扣的地方」 |
| 观澜 AI 演示问答 | 整屏布局:上半画布、下半对话;工具条、表达式栏、参数滑块均可用 |

### ❌ 不可用(依赖桌面宿主,手机版没有宿主)

| 功能 | 原因 |
|---|---|
| **本机资料库**(侧栏「🗄️ 本机资料库」) | 数据是电脑上 `数据库\qg_subjects.txt` 里的科目块,只有桌面宿主能读写;手机版会明确提示「手机版不支持」 |
| **破卷的本地高考真题档案检索** | 档案在电脑本地,宿主的 `kind:'mats'` 接口;手机版取不到 → 出题时**没有真实真题素材** |
| **破卷的必应联网检索** | 由宿主发起的联网检索;手机版取不到 |
| **破卷的「本机知识点档案」** | 就是上面「本机资料库」的检索入口 |
| 窗口最小化 / 最大化 / 关闭(─ ▢ ✕) | 手机上没有窗口,已隐藏 |

> ⚠️ **破卷在手机上的实际表现**:因为拿不到真题素材,难度二~五会反复重试到上限
> (程序要求「必须含 N 道真实真题」,而手机版一道也取不到),既慢又费 token。
> **手机上建议把难度选「难度一 · 真题 0%」**,让模型纯粹原创出题,一次即成。

### ⚠️ 打折扣的地方

- 观澜画布在手机上**不能缩放/平移**(canvas 引擎只处理单指拖动图元与鼠标滚轮;桌面版一直如此),双击复位在触屏上也不生效(浏览器不派发 `dblclick`)。
- 底部抽屉的拖拽是「拖动时跟手位移、松手吸附到 55% / 62% / 70% 三档」,不是连续自由高度。
- 左侧全屏抽屉宽度是 100%,屏幕上没有「抽屉外面」可点,所以遮罩做成**顶栏高度的一条**(写着「✕ 点这里关闭侧栏」);同时也支持向右滑动关闭。
- 窄屏下为了减轻手机 GPU 负担,只有重要度 ≥ 4 的知识点常显名称,其余在悬停/选中/搜索命中时临时点亮。

## 6. 常见问题

**Q:窗口提示端口被占用?**
换端口:`node server.js 8081`,然后手机访问 `http://<本机IP>:8081/`。

**Q:手机上点「出题训练」很久没反应?**
见上面「破卷在手机上的实际表现」,先确认 Key 已填、难度选「难度一」。

**Q:提示「本地代理 /api/ds 不可用(404)」?**
说明页面不是通过 `server.js` 打开的(比如直接双击 html 文件、或用别的静态服务器)。
请用 `启动手机版.bat` 或 `node server.js` 启动后再访问。

**Q:提示「无法连接 DeepSeek 接口」?**
电脑本身连不上外网(或被代理/防火墙拦了)。`/api/ds` 是由**电脑**去访问 DeepSeek 的。

**Q:改了文件手机上没变化?**
`server.js` 对所有资源都发了 `Cache-Control: no-cache`;
如果 Service Worker 已注册,它也是「网络优先」,在线时一定拿最新代码。真遇到顽固缓存,清一下浏览器数据即可。

## 7. 安全说明

- 服务器监听 `0.0.0.0`,同一局域网内任何设备都能访问 → **只在可信网络(家里/自己热点)里用**。
- 想只给自己电脑用:`node server.js 8080 127.0.0.1`。
- 页面 CSP 为 `default-src 'none'`,只放行本机资源与 `https://api.deepseek.com`。
- `server.js` 有目录穿越防护,且对非 GET/HEAD 的静态请求返回 405。
