# 词汇细分类 · 说明

> 三套互相独立、可叠加的词汇维度。全部为 **AI 整理初版（启发式/规则生成），待人工校对**。

## 1. 主题词汇（主题词汇.json / .txt）
- 20 个主题（t01 校园学习 … t20 世界常识）+ **t99「抽象与语法功能词」兜底组**（动词抽象义、虚词、代词、介词、连词等不具场景倾向的词）。
- 匹配方式：主题词典（_work\主题词典_part1/part2/补充.json）按“释义中文关键词子串 + 英文词形/词干”命中；一词可入多组；总归属 4,670 次，词号全部有效（1–3640）。
- 校对建议：主题组内有少量命中来自宽泛关键词（如“学/时/人”），逐组抽查后增删。

## 2. 派生词族（派生词族.json / .txt）
- 以根目录「词根检索索引」的词根族为骨架，族内列成员词（词号/词/词性），并给出 **chains（候选派生链）**。
- 链来源：① 约 300 组人工种子对（act→action→…）；② 词根族内“词干+常见后缀”规则探测。共 203 个词族、182 条链。
- 链的顺序与完整性待人工校对；中文释义可能需逐条核。

## 3. 难度分级（难度分级.json / .txt）
- **基础 710 词**：常用短词种子（_work\难度_基础种子.json，683 个）+ 长度 ≤3 的词。
- **核心 2844 词**：默认档。
- **拓展 86 词**：大写专名/全大写缩写/含符号词/词长 ≥13。
- 边界判定是规则近似：个别“看着不难的长词”可能进了核心而非基础，反之亦然，按需人工微调。
