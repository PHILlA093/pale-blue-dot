## 1. 词号引用约定

- 词表唯一词号 = 高考英语3500词根版_全量 的 no（1–3640，主表 1–3555、补遗 3556–3640）。
- 词汇细分类各文件通过 **no + word** 引用词条；引用词号必须有效（收尾有脚本校验）。
- 单词可同时出现在多个主题组；派生词族内同词不重复列两次以上。

## 2. 词汇细分类三套维度（互相独立、可叠加查询）

1. **主题场景**（约20组）：校园学习、家庭生活、饮食、健康医疗、体育文娱、旅行交通、自然环境、动物植物、科技信息、经济社会、职业人物、情感态度、性格品质、时间节日、服饰购物、居住建筑、艺术文学、政治法律、军事战争、常识世界。分组依据=主题词典规则匹配（词义/释义关键词），**启发式结果待人工校对**。
2. **派生词族（词性-派生链）**：以词根族（词根检索索引）为骨架，族内按词性-后缀生成派生链示例（如 decide→decision→decisive；act→action→active→activity→actor→actress），**链的完整性待人工校对**。
3. **难度分级**：基础（义务教育高频/日常短词种子+规则）、核心（高中核心，默认档）、拓展（专名/长难/低频书面词）。规则初版待校对。
