# 穷观 · 物理实验台（观澜物理模式第二块）设计契约

> 本文是**给实现它的 agent 看的接口契约**，不是给用户看的说明。
> 目的：把高中物理的**全部学生实验**做进「物理观澜」，让学生能真的"做"一遍：调参数 → 看到现象 → 记录数据 → 作图 → 得结论。
> 与「物理沙盒」（`js/psandbox.js`，符号即实体）**并列**：沙盒是"玩符号"，实验台是"做实验"。

## 4. 模块契约（`register(id, spec)`）

```js
window.QG_PSLAB.register('simple-pendulum', {
  id: 'simple-pendulum',
  name: '用单摆测量重力加速度',
  group: '力学',
  aim: '测量当地重力加速度 g,并分析误差来源',           // 一行实验目的
  principle: 'T = 2π√(L/g) → g = 4π²L/T²',              // 原理(含公式,文本)
  apparatus: ['长约 1 m 的细线', '金属小球', '铁架台', '毫米刻度尺', '秒表'],  // 器材
  steps: ['把细线一端固定…', '测摆长 L = 线长 + 球半径…', '…'],              // 步骤(文本数组)
  params: [                                              // 可调参数(右栏滑块)
    { key: 'L',    label: '摆长 L',   unit: 'm',  min: 0.4, max: 1.2, step: 0.01, value: 0.80 },
    { key: 'theta0', label: '初始摆角', unit: '°', min: 1,   max: 12,  step: 1,    value: 5 }
  ],
  // 派生的"真实"数据:必须由物理模型算出,允许带一点可解释的误差
  measure: function (p, ctx) {
    // p = 当前参数表;ctx = { rnd(seed), noise(sigma), t }
    // 返回一行数据(对象),键名用于数据表列;必须含本实验需要的最小可算集
    return { n: 30, t: 41.2, T: 1.373, L: 0.80, g: 9.79 };
  },
  columns: [                                             // 数据表列(与 measure 的键对应)
    { key: 'n', label: '全振动次数', unit: '' },
    { key: 't', label: '总时间 t',  unit: 's' },
    { key: 'T', label: '周期 T',    unit: 's' },
    { key: 'L', label: '摆长 L',    unit: 'm' },
    { key: 'g', label: 'g',        unit: 'm/s²' }
  ],
  // 图像:x/y 必须是 columns 里的键;fit 指定拟合方式
  graph: { x: 'L', y: 'T2', fit: 'linear', title: 'T²–L 图线', note: '斜率 k = 4π²/g' },
  // 结论:由数据算出,必须给出结论与误差来源
  conclude: function (rows, p, ctx) {
    return { value: 9.79, unit: 'm/s²', text: '测得 g = 9.79 m/s²,与当地重力加速度标准值 9.80 m/s² 相差 0.1%。',
             errors: ['摆长漏算球半径', '计时起止位置不同步', '摆角偏大导致周期偏大'] };
  },
  // 画面:在给定 canvas 上画出装置与现象(每帧调用;ctx 里自带 w/h/scale)
  draw: function (g, p, state) {
    // g = { c: CanvasRenderingContext2D, w: , h: , paper: '#F4F1EA', ink: '#26221C', font: fn }
    // state = { rows: [...], running: bool, t: 秒, phase: 0..1, hover: 元素名|null }
    // 只用 g.c 画;不要建 DOM(需要 DOM 的控件由核心统一提供)
  },
  // 可选:运行时推进自己的时间(核心每帧调用);不写就代表静态
  step: function (p, state, dt) { state.t += dt; },
  // 可选:交互(核心把指针事件转成图纸坐标后转给你)
  onPointer: function (ev, p, state) { /* ev = { type:'down'|'move'|'up', x, y } */ }
});
```

**约束**：
- `measure` 必须是**纯函数式**的"做一次测量"（可重复调用，返回值随参数/噪声变化），核心用它填数据表；`ctx.noise(sigma)` 给标准正态扰动，`ctx.rnd()` 给 [0,1)。
- `columns` 的键必须与 `measure` 返回的键一致（多出的键忽略；缺键报错）。
- `graph.x/graph.y` 若是派生量（如 `T2`），在 `measure` 里就返回它，别在核心算。
- 每个实验**至少 4 行可采数据**、**至少 1 张图**、**结论必须给出数值 + 单位 + 误差来源**。

## 7. 每个实验的验收（探针会逐条查，缺一即不合格）

1. `list()` 里出现该 `id`，`open(id)` 返回 true，`state().open === true`；
2. **参数真的影响结果**：改动至少 2 个不同参数后 `measure()` 的返回值**发生符合物理方向的变化**（例：单摆 L 变大 → T 变大；玻意耳 p 变大 → V 变小；双缝 d 变大 → Δy 变小）；
3. **能做出一张图**：`measure()` ≥ 5 次后 `graph().points.length ≥ 5`，有拟合时 `fit.r2 > 0.9`（数据本身是线性的实验必须如此）；
4. **结论有数值**：`conclude()` 返回 `{value, unit, text, errors[]}`，`errors` 至少 2 条；
5. **量纲与数量级合理**：例如 g 落在 9.6~10.1、n 落在 1.4~1.7、h 数量级 10⁻³⁴ J·s；
6. `draw()` 不抛异常（`run(1)` 后仍不抛），画布上**确实有像素被画**（探针比较前后像素签名）；
7. 全程 `0 console exceptions`。

## 9. 实现约定补充（核心落地后追认，2026-09-29）

下面四条是核心（`js/pslab.js`）在实现与加固时定下的**真实约定**，比 §4/§5 的示意更权威。**新写实验组时按这一节来。**

1. **`null` = "这次测量在这张图上没有有效值"，不是 0。**
   核心的 `coordOf(row,key)` 把 `null` / `undefined` / `''` 视为"缺值"：该行**不进图、也不进 `fit` 的 r²**（图下会注明"已跳过 N 个在这张图上无有效值的点"）；数据表里仍显示「—」。**真实的 `0` 照常进图**（别用 0 表示"没测到"）。
   例：光电效应在 ν<ν_c 时返回 `Uc: null` —— 若写成 0，会在 U_c–ν 图上塞进假点。
2. **`g.font` 是宽容签名**（四种调用都行，内部只认合法字体串；`true`/`false`/`undefined` 绝不会被拼进字体串）：
   ```js
   g.font(13)                  // 默认斜体衬线
   g.font(13, true|false)      // 布尔 = 是否斜体
   g.font(13, 'italic bold')   // 字符串 = 原样拼接（非法则净化，再非法退回默认）
   g.font(13, italic, bold)    // 三参布尔
   ```
   核心用一个"哨兵回读"校验（先写 `37px monospace` 再写待校验串，回读里若还带哨兵即判定非法），并按参数缓存结果。
3. **滑块 `step` 会被归一化，并在 `register` 时做参数体检**：
   未写 `step` → 0.01（保留兜底）；**显式 `step<=0`**、`step>量程`、`step==量程且两端非 0` → 一律改用 `(max-min)/100` 并记 warning。
   `min:0,max:1,step:1` 这类**二元开关量放行**（量程端点在 0）。
   体检项：`key` 唯一、`min<max`、`value ∈ [min,max]`、step 合理 —— **不合格只 warn 不拒收**，warning 进 `state().warnings`，也可用 `QG_PSLAB.audit()` 一次看全 20 个实验。
   滑块的 `step` 与 `setParam()` 的吸附**共用同一份归一化 step**。
4. **选项型参数**：`{ key, label, type:'select', options:[{value,label},…], value }` 会渲染成 `<select>`，`setParam(key, value)` 按**选项原值**匹配（字符串/数字都不丢）。没有 `min/max` 的参数**必须**写成 `select`（否则滑块会退回 0..100，根本选不到想要的取值）。目前只有 `mod.js` 的波长与阴极材料用它。

**另外记住两条实测出来的判据事实**（写探针时别踩）：
- **r² 必须在"扫自变量"时才有意义**：核心 `r2Of()` 用中心化 SS_tot，x 恒定时 `fitLinear` 直接返回 `fit:null`；固定参数下重复测量得到的是"同一个点附近的二维散布"，r² 会退化成相关系数平方（实测插针法 ~0.6、油膜法 ~0.3）。**所以"不改参数连测几次就要求 r²>0.9"是错的判据**。
- **`measure()` 有两种合理语义**（组里都在用，探针必须都兼容）：① 每次调用 = 一次独立测量（如磁/光/热/近代各组）；② 每次调用 = **推进数据系列的下一个点**（如 `mech.js`，6 点或 8 点一轮）。比较"改参数前后的同一行"时，请**每个参数状态各采 24 次**（6 与 8 的公倍数）再比均值。
