## 使用原则(重要)

1. **只作参考,不入库**:这些仓库里的教材 PDF / 笔记多为**有版权的出版物**。
   穷观仓库里**不放这些文件**,只记录来源与结论;知识点文本由我们按教材结构自行整理表述。
2. **不整仓库克隆**:先用 GitHub API / jsDelivr 列表接口看目录结构,只取需要的那几册,
   避免几百 MB~数 GB 的无谓下载。
3. 任何引用的数据(章节名、术语)都要**回到项目数据文件里核对**,不直接照抄。

## 解析结果(子代理回填)

### 2. high-school-notes(已解析 2026-09-19)

**结论:不能作为章节归属依据,只能作为"覆盖度清单"。**

| 项 | 实际情况 |
|---|---|
| 科目 | 数学 / 物理 / 生物 / 英语 / 语文 —— **没有化学** |
| 形式 | 100% Markdown,133 个文件,合计约 3.89 MB |
| 教材版本 | **不是人教版**:按"知识模块"组织,文件里检索 `人教/必修/选择性必修/课标/版本` **零命中** |
| 质量 | 两极分化:导数(17.6KB)、圆锥曲线(14KB)很扎实;集合(1.2KB)很薄;语文有大文件属题库堆料 |
| **许可** | **无 LICENSE**;README 只写「本项目仅供学习交流使用」,且自述二改自 [KnowledgeHierarchy](https://github.com/Ayvytr/KnowledgeHierarchy) → **默认保留全部权利,文字不可抄入穷观** |
| 取用 | GitHub API/raw 可用;单文件可用 `cdn.jsdelivr.net/gh/yulaoshizuikeai/high-school-notes@main/<路径>`;`data.jsdelivr.com` 列表接口返回 500,不要用 |

**允许的用法**:只当"主题覆盖度"参照——看它提到而穷观没有的知识点(如圆锥曲线二级结论:通径/焦半径/中点弦/硬解定理;
导数高阶:极值点偏移/隐零点/双变量),由我们**自己组织表述**后补进数据。
**禁止**:整段摘抄、大段改写、把文件复制进仓库。

### 1. ChinaTextbook 教材库(已解析)

**结论:唯一可用通道是 `raw.githubusercontent.com`,是未获授权的民间镜像,PDF 只做内部核对、绝不进仓库。**

| 项 | 实际情况 |
|---|---|
| 通道 | ✅ `raw.githubusercontent.com`(实测 206 + `%PDF-1.7`);✅ `api.github.com`(无 token **限流 60 次/小时**);❌ `github.com` 网页本机打不开(超时);⚠️ jsDelivr 只 301 跳回 raw,无增益 |
| 规模 | **43.42 GiB / 1905 个 PDF + 466 个分卷**;**无 Git LFS**(raw 拿到的是真 PDF) |
| 高中人教版 | 数学 A 版 5 册(必修一 66.7MB 是 **.pdf.1+.pdf.2 分卷,需按字节拼接**)/ B 版 7 册、物理 6 册、化学 5 册、英语 7 册,**共 31 个文件 526.4 MiB** |
| 版本 | 全部是 `普通高中教科书·X`(2019 课标新教材);**库里没有 2004 大纲版** |
| 许可 | **无 LICENSE、README 里连版权声明都没有** → 未声明许可。教材著作权属人教社 |
| 中文直链 | raw 接受字面中文路径,**只有空格要写 `%20`** |
| Release | 教材库**无 Release**;唯一 Release 在配套工具库,v0.0.1 只有 `mergePDFs.exe`(合分卷用,**没有 PDF→文本 能力**) |

直链前缀:`https://raw.githubusercontent.com/TapXWorld/ChinaTextbook/master/`
(例:`高中/化学/人教版-人民教育出版社/普通高中教科书·化学必修%20第一册.pdf`)

### 3. byoungd/up 学习方法(已解析)

**结论:它不是"应试学习方法书",是《人生进阶指南 · AI 时代终身学习指南》(中英双语开放书稿),面向成年终身学习者,对高中应试几乎无弹药。**

- 体量:174 个 md / 1.45 MB;成品 PDF 339 页 62 章;63k stars
- **许可:内容 CC BY-NC 4.0(禁止商业使用)+ 代码 MIT** ⚠️ —— 若穷观要商业化,这本书的**文字不能直接用**(方法与思想本身不受版权保护,可以借鉴后自行表述)
- 全书 79 个中文 md 全量扫描:**错题本 / 遗忘曲线 / 费曼 / 番茄钟 / 康奈尔 / 思维导图 / 考试策略 / 刷题 / 真题 / 高考 全部缺席或仅作非方法性提及**
- **可产品化的 13 条机制**(最值得抄的是思路,不是文字):
  1. **四点证据链**:基线 → 即时表现 → 延迟保持 → 迁移(同一任务四份样本)
  2. 间隔检查点(当天/1天/3-7天/14天/30天)**按表现调整**,不套固定遗忘曲线
  3. 主动回忆六步回路:定义/首版/诊断/定向输入/**合上材料产出**/反馈
  4. **六层错误分层诊断**(听力/阅读/通用各一套)→ 把"错因"做成结构化枚举
  5. **首版不可被润色覆盖**(首版是测量不是判决)
  6. **支架阶梯 + 撤架复测**(以字幕为例,六步)
  7. **未知项五选一决策队列**(放过/语境推断/快速查阅/主动学习/专业核验),一轮只选 5-8 个词块
  8. 词汇八维卡 + 单决定卡
  9. 四查周复盘(完成/质量/保持/迁移)+ 0-2 分量表
  10. **三档容量**(完整日/压缩日/恢复日)+ 中断后 24 小时内极小输出
  11. 九十天周期三阶段门槛 + 45 分钟五段闭环
  12. **AI 三版本对照**(独立版/辅助版/延迟独立版)+ 速度债判读
  13. 分技能固定遍数流水线(阅读五遍/写作五次修订/听力五遍)
- ⚠️ **该书明确反对打卡/streak/时长统计**:"卡片数量、连续打卡和成熟词数只有在能够改变决定时才值得记录"
- 唯一面向学生的一章是《家庭学习篇》,自我定位为**初中阶段**

### 1b. ChinaTextbook-tools(已解析)

- 只有 v0.0.1,资产是 **`mergePDFs-windows-amd64.exe`(2.2 MB)**,用途是**把分卷 .pdf.N 合并成一个 PDF**;
  **没有任何 PDF→文本 / 目录提取 / 词表提取 能力** → 这部分要我们自己写(见下)
- ⚠️ 第三方 exe,运行需谨慎;分卷其实可以直接按字节拼接(`copy /b a.pdf.1+a.pdf.2 out.pdf`),不必用它
