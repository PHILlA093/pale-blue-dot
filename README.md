# 🌌 穷观 V2.4.2 · 高中知识词云系统

> **授权:PolyForm Noncommercial 1.0.0 —— 允许任何非商业用途(个人学习/教学/研究),禁止任何形式的商业使用。**详情见 [LICENSE](LICENSE)

以**图结构**为核心的 3D 知识网络学习工具:知识点为节点、相关性为连线,整张网在三维空间中按"重要度"与"相关度"排布。
另含两个 AI 模块:**破卷**(AI 出题训练)与**观澜**(AI 演示问答 + 可动示意图)。

## 快速开始

**桌面版(推荐)**:双击根目录的 **`启动穷观学习.bat`** —— 它会自动定位并启动 `桌面版\穷观学习.exe`。
(直接双击 `桌面版\穷观学习.exe` 效果一样;`桌面版\` 里也放了一份同样的启动器,那个文件夹单独拷走时用它。)

启动前请确认该目录下同时存在下列文件——**这不是一个真正的单文件程序**,WebView2 的运行时 DLL 必须一起分发:

```
桌面版\
├── 穷观学习.exe                        ← 主程序(网页资源全部内嵌其中)
├── Microsoft.Web.WebView2.Core.dll     ┐
├── Microsoft.Web.WebView2.WinForms.dll ├ WebView2 运行时,必须同目录
├── WebView2Loader.dll                  ┘
├── 使用说明.txt
├── 数据库\qg_corpus.txt                ← 本机语料库(高考真题等,≈44 MB)
└── 穷观学习.exe.WebView2\               ← 运行期数据(自动生成,可删)
```

> 旧名 `高中数学知识库.exe` 已更名;若沿用旧版本,重命名 exe 时**必须连同
> `xxx.exe.WebView2\` 数据目录一起改名**,否则 WebView2 会新建一份空配置(API Key 会"丢失")。
> 图标 `favicon.ico` 是穷观唯一的 logo 源:既内嵌进 exe(资源管理器/任务栏),又作为页面 favicon。

**网页版**:直接打开 `index.html` 也能用(离线可用,依赖已本地化在 `vendor/`),
但没有本机资料库、没有原生窗口,AI 功能改为浏览器直连 DeepSeek。

## 三个模块

| 模块 | 入口 | 说明 |
|---|---|---|
| **知识云** | 主窗 | 3D 知识网络:搜索、点选、聚焦、板块筛选、新增知识点 |
| **破卷** | 主窗右下角「🎯 破卷」 | AI 出题:每批固定 4 题、同一题型、同一难度;难度 1~5 对应真题占比 0/25/50/75/100% |
| **观澜** | 侧栏「🌊 观澜 · AI 演示问答」 | AI 讲解 + 「🎬 动态演示」生成可动数学示意图;对话**仅存内存**,关窗即清 |

两个 AI 模块**共用同一把 DeepSeek API Key**(存本机 localStorage,不上传)。Key 在破卷窗顶部或观澜输入框旁填写。

## 科目与规模

| 科目 | 板块 | 节点 | 关联 |
|---|---|---|---|
| 数学 | 10 | 115 | 263 |
| 化学 | 8 | 86 | 219 |
| 物理 | — | 92 | — |
| 英语 | — | 1978 | — |

> 数字取自当前 `js/data*.js`;数据文件由各自的维护流程生成,`app.js` 只负责渲染。

**本机语料库**(`数据库\qg_corpus.txt`)当前约 33,000 块,其中高考数学真题 15,640 块
(1952–2026 共 775 套,原卷 + 解析成对)。检索时**近十年(2017–2026)真题权重 ×3**,
更早年份按普通题权重 1.0;该权重可在 `桌面版\build\Program.cs` 的
`RecentFrom / RecentTo / WRecent / WNormal` 四个常量处调整。

## 三维布局规则

| 维度 | 含义 |
|---|---|
| **高度(Y 轴)** | 知识点重要度:越高越重要、越总体 |
| **半径(中心→外)** | 相关度:越靠中心相关度越高 |
| **颜色** | 所属板块 |
| **节点大小** | 重要度 |
| **连线** | 知识点之间的相关性(含跨板块衔接) |

同心金色环 = 核心区;淡蓝圆盘 = 重要度层级。

## 交互操作

| 操作 | 效果 |
|---|---|
| 拖拽空白处 | 旋转视角 |
| 滚轮 | 缩放 |
| 单击节点 | 查看详情(右侧面板:讲解 / 重要度 / 相关度 / 相关知识) |
| 双击节点 | 相机聚焦该知识点 |
| 左侧板块勾选 | 显示/隐藏对应板块的知识点与连线 |
| 搜索框 | 多关键词按"同时包含"匹配,结果按重要度排序 |
| 右上角 `─ ▢ ✕` | 无边框窗口的最小化 / 最大化 / 关闭 |
| `F11` | 主窗最大化切换 |

## 源码结构

仓库:<https://github.com/PHILlA093/pale-blue-dot> —— `main` 分支为桌面版;`mobile-apk` 分支额外含
`手机版/`(PWA + Android APK),两分支的 `js/ css/ vendor/` 与三个 html 同源。

```
index.html        主窗(知识云 + 侧栏 + 详情卡)
train.html        破卷窗(AI 出题)
guanlan.html      观澜窗(AI 演示问答)
css/style.css     主窗与观澜共用的样式
js/app.js         3D 知识云引擎(three.js)
js/mainbridge.js  主窗 ⇄ 子窗桥:状态心跳、定位指令、知识云自动上传
js/train.js       破卷逻辑:素材检索、提示词、出题与校验
js/demo.js        观澜逻辑:对话、演示调度、独立窗启动
js/glcanvas.js    动态演示画布引擎(自有表达式解析器,不用 eval)
js/gltemplates.js 数学演示模板库(31 个模板)
js/data*.js       各科知识库数据
vendor/           three.js r128 + OrbitControls + MathJax(均已本地化,零外链)
桌面版/build/      宿主源码与构建脚本(Program.cs / _rebuild.ps1 / _makeicon.ps1 / _qa 回归探针)
docs/DESIGN.md     架构设计说明
docs/研究资料/      各科知识库的重建资料、工具脚本与统计报告(原始大体积语料不入库,见该目录 README)
docs/宣传片/        宣传片生成流水线(脚本与说明;渲染帧、wav 等中间产物不入库)
```

## 构建桌面版

```
powershell -File 桌面版\build\_rebuild.ps1
```

用系统自带的 `csc.exe` 编译(遵守 **C# 5** 语法),把 `index.html / css / js / vendor /
train.html / guanlan.html` 全部作为资源内嵌(`web.*`),先输出到 ASCII 临时路径再复制成品
(中文路径下 csc 无法直接写 `/out:`)。

架构细节见 `docs/DESIGN.md`。
