穷观 V2.4.2 · 高中知识词云系统(Windows 原生桌面版)
====================================================

【使用方法】
  双击「穷观学习.exe」即可打开,无需安装任何软件。
  也可以双击本文件夹里的「启动穷观学习.bat」——上一层目录里还放了一份同样的启动器,
  双击它会自动找到这里的 exe。
  整个文件夹可拷贝到 U 盘或任意电脑使用。

【本文件夹内容】
  穷观学习.exe                      主程序(网页资源已全部内嵌,双击即用,图标即穷观 logo)
  Microsoft.Web.WebView2.Core.dll   WebView2 组件(随程序一起分发,勿删)
  Microsoft.Web.WebView2.WinForms.dll
  WebView2Loader.dll
  数据库\qg_corpus.txt              本机资料库(高考真题等,约 44 MB)
  数据库\qg_subjects.txt            自动上传的知识云数据(可删,会重新生成)
  穷观学习.exe.WebView2\            个人知识点、自绘函数与 API Key 等(勿删,卸载默认保留)

  ⚠ 这不是"单个 exe":上面 3 个 WebView2 的 dll 必须与 exe 放在一起,
    少一个都打不开。

【运行环境要求】
  · Windows 11(本程序基于系统自带的 .NET Framework 4.8 与 WebView2 运行时,
    无需额外安装任何开发环境)
  · 若首次运行提示找不到 WebView2 运行时:打开「设置 → 应用 → 已安装的应用」,
    把 Microsoft Edge 更新到最新版即可(Edge 会自带 WebView2 运行时)

【功能速览】
  · 3D 知识网络:数学 132 点 / 化学 86 点 / 物理 92 点 / 英语 3053 点 / 生物 137 点。
    高度 = 重要度,半径 = 相关度,颜色 = 板块,连线 = 知识点之间的相关性。
  · 操作:拖拽空白处旋转视角 / 滚轮缩放 / 单击节点看详情 / 双击聚焦 /
    左侧板块勾选可单独显示或隐藏。
  · 关键词搜索:顶部搜索框输入(如:导数、椭圆、方差、正弦定理、二面角),
    支持多个关键词(空格或逗号分隔),需**全部命中**;点击结果自动飞向该知识点。

  · 🎯 破卷(AI 出题训练):主窗右下角进入。
    每批固定 4 道,同一题型、同一难度;难度与素材偏好独立选择。
    来源分为本地原文匹配 / 联网原文匹配 / 来源待核实 / AI 生成。
    原文匹配仅指题干和选项,不代表答案或网页真题身份已审核。
    素材不足时如实标记,不为来源比例重复出题;出题失败保留上一批。
    英语题目使用英语,解析使用中文。

  · 🌊 观澜(AI 讲解 + 动态演示):侧栏进入,打开独立窗口。
    提问后点「🎬 动态演示」可生成会动的数学示意图(31 个内置模板,
    匹配不到时由 AI 现场生成)。点「📷」或直接 Ctrl+V 粘贴 / 把图片拖进来,
    可以附一张**题图或教材截图**,AI 会先读图再讲解。

【关于 API Key】
  破卷与观澜共用同一把 DeepSeek API Key,只保存在本机,**不上传、不写入日志**。
  在破卷窗顶部或观澜输入框旁填写并保存即可。
  「🗑 清除」会删除本机保存的 Key 并清掉运行日志。

【数据扩展】
  网页版源码位于上层目录(js/data.js 等);如需扩充知识点,
  修改数据后重新打包即可(与本版共用同一份数据)。
